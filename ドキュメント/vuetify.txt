# Vuetify 3 Grid System - 正しい使い方

## 🎯 公式の基本ルール

### 基本構造
```vue
<v-container>
    <v-row>
        <v-col>コンテンツ</v-col>
    </v-row>
</v-container>
```

**階層ルール**:
1. `<v-container>`: 最外部のコンテナ(ページごとに1つが原則)
2. `<v-row>`: 行を定義(必要に応じて複数可)
3. `<v-col>`: 列を定義(12カラムシステム)

---

## ✅ v-rowは複数使ってOK!

### パターン1: 複数の`<v-row>`でセクション分け(推奨)
```vue
<v-container>
    <!-- セクション1 -->
    <v-row>
        <v-col cols="12" md="6">左コンテンツ</v-col>
        <v-col cols="12" md="6">右コンテンツ</v-col>
    </v-row>

    <!-- セクション2 -->
    <v-row>
        <v-col cols="12" md="4">カード1</v-col>
        <v-col cols="12" md="4">カード2</v-col>
        <v-col cols="12" md="4">カード3</v-col>
    </v-row>

    <!-- セクション3 -->
    <v-row>
        <v-col cols="12">フッター</v-col>
    </v-row>
</v-container>
```

**メリット**:
- セクションごとに異なるレイアウトを適用できる
- 各行で`justify`, `align`, `dense`, `no-gutters`を個別設定可能
- コードが読みやすく、保守しやすい

### パターン2: 1つの`<v-row>`に複数`<v-col>`(シンプルな場合)
```vue
<v-container>
    <v-row>
        <v-col cols="12" md="6">左</v-col>
        <v-col cols="12" md="6">右</v-col>
        <!-- cols="12"なので自動で改行される -->
        <v-col cols="12">下部コンテンツ</v-col>
    </v-row>
</v-container>
```

**メリット**:
- シンプルなレイアウトなら1つの`<v-row>`で完結
- 全列に同じ余白設定を適用したい場合に便利

## 📊 使い分けまとめ

| 用途 | 推奨手段 | 理由 |
|------|----------|------|
| **複雑なレスポンシブレイアウト** | Grid System (`<v-row>`, `<v-col>`) | 12カラムシステム、ブレークポイント対応 |
| **フォーム(横並び + 縦並び混在)** | Grid System | 画面サイズで並び方を変更 |
| **詳細表示(固定2列)** | Flexbox (`d-flex`) | シンプル、余白管理が楽 |
| **ボタン配置(両端など)** | Flexbox + `<v-spacer />` | 柔軟な配置 |

            username: response.data.username,
            employee_id: response.data.employee_id,

        };

        handleApiError(error, 'pages.users.detail.error');

        loading.value = false;

async function submitForm() {
    if (submitting.value) return;

    submitting.value = true;
    try {
        const updateData = {
            username: formData.value.username,
            employee_id: formData.value.employee_id,
            is_admin: formData.value.is_admin,
            is_active: formData.value.is_active,

            username: formData.value.username,
        });

        router.replace({ name: ROUTE_NAMES.ADMIN.USERS.LIST });
    } catch (error) {
        handleApiError(error);
    } finally {
        submitting.value = false;
    }
}

onMounted(() => {

});

<script setup>
import { computed } from 'vue';
import { useBreadcrumbs } from '@/composables/useBreadcrumbs';
import { ICONS } from '@/constants/icons';
import { ICON_SIZES } from '@/constants/theme';

const { breadcrumbs: autoBreadcrumbs } = useBreadcrumbs();

const props = defineProps({
    appTitle: {
        type: String,
        default: 'デフォルトのタイトル名',
    },
    headerHeight: {
        type: [String, Number],
        default: 64,
    },
    headerElevation: {
        type: [String, Number],
        default: 2,
    },
    pageButtons: {
        type: Array,
        default: () => [],
        validator: (buttons) => {
            const isValid = buttons.every((btn) => {
                const hasId = btn.id && typeof btn.id === 'string';
                const hasValidType =
                    btn.type &&
                    [
                        'primary',
                        'secondary',
                        'error',
                        'warning',
                        'info',
                        'success',
                    ].includes(btn.type);

                if (import.meta.env.DEV) {
                    if (!hasId) {
                        console.error(
                            '[Header] Button missing required "id" field:',
                            btn,
                        );
                    }
                    if (!hasValidType) {
                        console.error(
                            '[Header] Button missing or invalid "type" field:',
                            btn,
                        );
                    }
                }

                return hasId && hasValidType;
            });

            return isValid;
        },
    },
    breadcrumbs: {
        type: Array,
        default: null,
    },
});

const displayBreadcrumbs = computed(() => {
    if (props.breadcrumbs !== null) {
        return props.breadcrumbs;
    }
    return autoBreadcrumbs.value;
});
</script>

<template>

                            {{ item.title }}
