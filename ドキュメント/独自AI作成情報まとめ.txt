## STEP 5: RAG構築

### 5-1. RAG構築スクリプト作成

```bash
cd ..  # vue-ai-project/ に戻る
```

`create_knowledge_base.py` を作成:

```python
from langchain.document_loaders import DirectoryLoader, TextLoader, UnstructuredHTMLLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.vectorstores import Chroma
from langchain.embeddings import HuggingFaceEmbeddings
import os

print("🚀 Vue.js3 知識ベース作成開始...")

# 1. ドキュメント読み込み
print("\n📖 ステップ1: ドキュメント読み込み中...")

loaders = []

# Vue公式ドキュメント
if os.path.exists("data/vue-docs"):
    loader_vue = DirectoryLoader(
        "data/vue-docs",
        glob="**/*.html",
        loader_cls=UnstructuredHTMLLoader
    )
    loaders.append(loader_vue)

# Vuetifyドキュメント
if os.path.exists("data/vuetify-docs"):
    loader_vuetify = DirectoryLoader(
        "data/vuetify-docs",
        glob="**/*.html",
        loader_cls=UnstructuredHTMLLoader
    )
    loaders.append(loader_vuetify)

# あなたの過去プロジェクト
if os.path.exists("data/my-project"):
    loader_project = DirectoryLoader(
        "data/my-project",
        glob="**/*.vue",
        loader_cls=TextLoader
    )
    loaders.append(loader_project)
    
    # JSファイルも読み込み
    loader_js = DirectoryLoader(
        "data/my-project",
        glob="**/*.js",
        loader_cls=TextLoader
    )
    loaders.append(loader_js)

# 全ドキュメント読み込み
docs = []
for loader in loaders:
    try:
        docs.extend(loader.load())
    except Exception as e:
        print(f"⚠️  警告: {e}")

print(f"✅ {len(docs)} 個のドキュメント読み込み完了")

# 2. テキスト分割
print("\n✂️  ステップ2: テキスト分割中...")
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200,
    length_function=len,
)
chunks = text_splitter.split_documents(docs)
print(f"✅ {len(chunks)} 個のチャンクに分割完了")

# 3. 埋め込みモデル準備
print("\n🧠 ステップ3: 埋め込みモデル準備中...")
```

## STEP 6: AIアシスタント作成

### 6-1. アシスタントスクリプト作成

`vue_assistant.py` を作成:

```python
import sys
import ollama
from langchain.vectorstores import Chroma
from langchain.embeddings import HuggingFaceEmbeddings

def initialize_db():
    """ベクトルデータベース初期化"""
    embeddings = HuggingFaceEmbeddings(
        model_name="intfloat/multilingual-e5-base",
        model_kwargs={'device': 'cpu'}
    )
    vectordb = Chroma(
        persist_directory="./vue_knowledge",
        embedding_function=embeddings
    )
    return vectordb

def ask_vue_ai(question, vectordb):
    """Vue.js3 AIアシスタントに質問"""
    
    # 類似コード検索
    print("🔍 関連コードを検索中...")
    similar_docs = vectordb.similarity_search(question, k=3)
    
    # コンテキスト構築
    context = "\n\n---\n\n".join([doc.page_content for doc in similar_docs])
    
    # プロンプト構築
    prompt = f"""あなたはVue.js 3 + Vuetify 3 + Piniaのエキスパートです。

【参考コード・ドキュメント】
{context}

【質問】
{question}

【回答ルール】
- Composition APIを使用
- TypeScriptを想定
- Vuetify 3の最新コンポーネント使用
- Piniaを使う場合はsetup stores形式
- 完全に動作するコードを出力
- 日本語で説明を添える
- コメントも日本語で記述
"""
    
    # AI生成
    print("🤖 AIが回答を生成中...")
    response = ollama.chat(
        model='deepseek-coder:6.7b',
        messages=[
            {
                'role': 'system',
                'content': 'あなたはVue.js 3のエキスパートです。実用的で完動するコードを生成してください。'
            },
            {
                'role': 'user',
                'content': prompt
            }
        ]
    )
    
    return response['message']['content']

def main():
    if len(sys.argv) < 2:
        print("使い方: python vue_assistant.py '質問内容'")
        print("例: python vue_assistant.py 'Vuetifyでデータテーブル作って'")
        return
    
    question = " ".join(sys.argv[1:])
    
    print("🚀 Vue.js3 AIアシスタント起動")
    print(f"❓ 質問: {question}\n")
    
    # DB初期化
    vectordb = initialize_db()
    
    # 質問処理
    answer = ask_vue_ai(question, vectordb)
    
    # 回答表示
    print("\n" + "="*60)
    print("💡 回答:")
    print("="*60)
    print(answer)
    print("="*60)

if __name__ == "__main__":
    main()
```


**原因:** Ollamaサービス未起動

**解決策:**
```bash
# バックグラウンド起動
ollama serve &

# または Windows
# タスクトレイにOllamaアイコンがあるか確認
# なければ再起動
```

### ❌ 問題: `Error: model 'deepseek-coder:6.7b' not found`

**原因:** モデル未ダウンロード

**解決策:**
```bash
ollama pull deepseek-coder:6.7b
```

**原因:** dataフォルダが空、またはパス間違い

```bash
ls data/
```

**解決策:**
```bash

ollama pull codellama:7b

model='codellama:7b'
```

```bash
ollama pull deepseek-coder:1.3b
```
